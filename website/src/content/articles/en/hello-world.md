# My first article, what an emotion.

This website is currently running on an old PC I built in 2014 that still has some life left in it.

I'm going to use this home server to do whatever I want technically, share my projects and my ideas.

The CI/CD is very simple, it's proportional to the projects I want to host on this server.

For every folder inside `side-projects/` containing a `Dockerfile`, a script will automatically deploy the image and register the subdomain in Caddy.

You can see the entire project on [GitHub](https://github.com/lorys/lorys).
