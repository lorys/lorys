# TV Series Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recognise TV episodes from scene filenames, group them by show with TMDB TV metadata, browse them by season, and chain episodes with a "Épisode suivant" countdown.

**Architecture:** Episodes stay ordinary entries of `movies` in `MOVIES_INFOS_PATH` (own `id`/`file`, `kind: "episode"`), so streaming, subtitles, conversion and progress are untouched. A new top-level `shows` object holds per-show TMDB data and per-season episode details. The frontend groups episodes into show tiles using pure helpers in `public/js/episodes.js`; the player gets a title override and a next-episode countdown.

**Tech Stack:** Node ≥ 22.9 (ESM, `node:test`), Fastify 5, vanilla JS frontend, TMDB API v3.

**Spec:** `docs/superpowers/specs/2026-10-12-series-design.md`

## Global Constraints

- Detection is filename-only (basename); folder names are ignored. No marker → movie, exactly as today.
- TMDB language stays `fr-FR`; all user-facing text is French (`Séries`, `Saison N`, `Épisode N`, `Épisode suivant`, `S1:É2`).
- One `searchTv` + `tvDetails` per show and one `seasonDetails` per season per scan; matched data is reused on later scans unless `force`.
- Episode entries keep every movie field (`genres: []`, `cast: []`, `director: null`, …) so existing code reading items keeps working.
- Credits threshold is the server's `isFinished` rule: `duration - position <= Math.max(60, duration * 0.05)`.
- Countdown: 10 s, pauses while the video is paused.
- Genre rows, "Ajoutés récemment", "Les mieux notés" and "Autres" stay movies-only; shows live in the "Séries" row (and "Reprendre la lecture").
- No new dependencies. Tests run with `npm test` (`node --test`).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

- Library scanned before this change: an episode file previously *matched as a movie* must be re-looked up as an episode (keeping its id), not kept as a movie forever → test in Task 3.
- Movie names with numbers or resolutions (`Apollo.13.1995`, `Ocean.s.11`, `Movie.1920x1080`, `2001 A Space Odyssey 1968`) must not be detected as episodes, and a bare `S01E02.mkv` (no show name) stays a movie → tests in Task 1.
- A converted episode (`.mkv` renamed to `.mp4` through `renameMovieEntry`) keeps its episode data and isn't looked up again → test in Task 3.
- Two files for the same episode (720p + 1080p): "next episode" must not loop between them → test in Task 4.
- A show whose last available episode was finished must leave "Reprendre la lecture" and its Play button must restart at the first episode → test in Task 4 (`episode: null`) and wiring in Task 6.

```js
// S01E02, S1E2, S01 E02, S01E01E02, S01E01-E02, S01E01-02, 1x02, 1x02-03 (after dots/underscores became spaces).
const EPISODE_MARKER =
  /(?:^|[\s-])(?:s(\d{1,2}) ?e(\d{1,3})(?:-?e(\d{1,3})|-(\d{1,3})(?=[\s-]|$))?|(\d{1,2})x(\d{2,3})(?:-(\d{2,3}))?)(?=[\s-]|$)/i;

/** Basename without extension, [tags] removed, dots/underscores turned into single spaces. */
function cleanName(filename) {
  let name = path.basename(filename, path.extname(filename));
  name = name.replace(/\[[^\]]*\]/g, ' '); // [release group], [1080p]...
  return name.replace(/[._]+/g, ' ').replace(/\s+/g, ' ').trim();
}

function tidyTitle(name) {
  return name.replace(/[()\[\]{}]/g, ' ').replace(/\s+-\s*$/, '').replace(/\s+/g, ' ').trim();
}

/**
 * Turn a filename like "Le.Fabuleux.Destin.d'Amelie.Poulain.2001.1080p.BluRay.x264.mkv"
 * into { title: "Le Fabuleux Destin d'Amelie Poulain", year: 2001 }.
 */
export function parseMovieFilename(filename) {
  let name = cleanName(filename);

  let year = null;
  const yearMatches = [...name.matchAll(/(?:^|[\s(\[-])((?:19|20)\d{2})(?=$|[\s)\]-])/g)];
  // Use the last year-looking token that isn't at the very start ("2001 A Space Odyssey 1968").
  const yearMatch = yearMatches.filter((m) => m.index > 0).at(-1);
  if (yearMatch) {
    year = Number(yearMatch[1]);
    name = name.slice(0, yearMatch.index);
  }

  const tag = name.match(STOP_TAGS);
  if (tag && tag.index > 0) name = name.slice(0, tag.index);

  const title = tidyTitle(name);
  return { title: title || path.basename(filename, path.extname(filename)), year };
}

/**
 * Turn "Breaking.Bad.S01E02.1080p.WEB.x264.mkv" into
 * { showTitle: "Breaking Bad", year: null, season: 1, episode: 2, episodeEnd: 2 }.
 * Returns null when the name has no episode marker or no show name before it.
 */
export function parseEpisodeFilename(filename) {
  const name = cleanName(filename);
  const marker = name.match(EPISODE_MARKER);
  if (!marker) return null;
  const season = Number(marker[1] ?? marker[5]);
  const episode = Number(marker[2] ?? marker[6]);
  const end = Number(marker[3] ?? marker[4] ?? marker[7] ?? episode);

  let title = name.slice(0, marker.index).replace(/[\s-]+$/, '');
  let year = null;
  // "Doctor Who 2005" / "Doctor Who (2005)": the year tells remakes apart on TMDB.
  const yearMatch = title.match(/\s\(?((?:19|20)\d{2})\)?$/);
  if (yearMatch) {
    year = Number(yearMatch[1]);
    title = title.slice(0, yearMatch.index);
  }
  const tag = title.match(STOP_TAGS);
  if (tag && tag.index > 0) title = title.slice(0, tag.index);

  const showTitle = tidyTitle(title);
  if (!showTitle) return null;
  return { showTitle, year, season, episode, episodeEnd: Math.max(end, episode) };
}

/** Groups episodes of the same show: "Le Bureau des Légendes" → "le bureau des legendes". */
export function showKey(title) {
  return title
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, ' ')
    .trim();
}
```

function fakeTmdb({ failShow = null, failSeason = null } = {}) {
  return {
    calls: [],
    async searchMovie(title) {
      this.calls.push(['searchMovie', title]);
      return { id: 7 };
    },
    async movieDetails(id) {
      return { id, title: 'Un film', original_title: 'A movie', genres: [{ name: 'Drame' }], credits: {} };
    },
    async searchTv(title, year) {
      this.calls.push(['searchTv', title, year]);

      return title === 'Inconnue' ? null : { id: 100 };

    async tvDetails(id) {
      this.calls.push(['tvDetails', id]);

/**
 * Sync MOVIES_INFOS_PATH with the content of MOVIES_PATH.
 * Only new files (and previously unmatched ones) hit TMDB unless `force` is set.
 * Episodes ("Show.S01E02…") are grouped by show: one TMDB lookup per show and per season.
 */
export async function scanMovies(config, { force = false, logger = console, tmdb } = {}) {
  const previous = await readMoviesInfos(config.moviesInfosPath);
  const known = new Map(previous.movies.map((m) => [m.file, m]));
  const files = await listVideoFiles(config.moviesPath);

  const result = [];
  const moviesToLookUp = [];
  const episodesByShow = new Map();
  // Existing entries keep their id (watch progress is keyed by it), even when a conversion renamed the
  // file; new files get one derived from their path, made unique if a converted movie already holds it.
  const usedIds = new Set(files.map((f) => known.get(f.file)?.id).filter(Boolean));
  const newId = (file) => {
    let id = movieId(file);
    for (let n = 1; usedIds.has(id); n++) id = movieId(`${file}#${n}`);
    usedIds.add(id);
    return id;
  };
  for (const f of files) {
    const existing = known.get(f.file);
    const episode = parseEpisodeFilename(f.file);
    // Older versions matched episodes as movies: those are looked up again, as episodes.
    const sameKind = (existing?.kind === 'episode') === Boolean(episode);
    if (existing && existing.matched && sameKind && !force) {
      result.push({ ...existing, size: f.size, addedAt: f.addedAt });
      continue;
    }
    const id = existing?.id ?? newId(f.file);
    if (!episode) {
      moviesToLookUp.push({ id, ...f, parsed: parseMovieFilename(f.file) });
      continue;
    }
    const key = showKey(episode.showTitle);
    if (!episodesByShow.has(key)) episodesByShow.set(key, []);
    episodesByShow.get(key).push({ id, ...f, parsed: episode });
  }

  const stats = { total: files.length, lookedUp: 0, matched: 0, unmatched: 0, errors: 0 };
  const shows = {};
  let client;

  async function lookUpMovie(base) {
    try {
      const hit = await client.searchMovie(base.parsed.title, base.parsed.year);
      if (hit) {
        result.push(toMovieInfo(base, await client.movieDetails(hit.id)));
        stats.matched++;
      } else {
        result.push(unmatchedInfo(base));
        stats.unmatched++;
        logger.warn?.(`No TMDB match for "${base.file}" (searched "${base.parsed.title}"${base.parsed.year ? ` ${base.parsed.year}` : ''})`);
      }
    } catch (err) {
      // Keep the previous entry (or a placeholder) so the movie stays visible; it is retried next scan.
      result.push(known.get(base.file) ?? unmatchedInfo(base));
      stats.errors++;
      logger.error?.(`TMDB lookup failed for "${base.file}": ${err.message}`);
    }
  }

  async function lookUpShow(key, episodes) {
    const { showTitle } = episodes[0].parsed;
    const previousShow = previous.shows[key];
    let show = previousShow?.matched && !force ? { ...previousShow, seasons: { ...previousShow.seasons } } : null;
    try {
      if (!show) {
        const year = episodes.find((e) => e.parsed.year)?.parsed.year ?? null;
        const hit = await client.searchTv(showTitle, year);
        show = hit ? toShowInfo(key, await client.tvDetails(hit.id)) : unmatchedShow(key, showTitle);
        if (!hit) logger.warn?.(`No TMDB match for the show "${showTitle}"${year ? ` ${year}` : ''}`);
      }
    } catch (err) {
      // Keep the previous entries (or placeholders) so the episodes stay visible; retried next scan.
      shows[key] = previousShow ?? unmatchedShow(key, showTitle);
      for (const base of episodes) {
        const old = known.get(base.file);
        result.push(old?.kind === 'episode' ? old : toEpisodeInfo(base, shows[key]));
      }
      stats.errors += episodes.length;
      logger.error?.(`TMDB lookup failed for the show "${showTitle}": ${err.message}`);
      return;
    }
    if (show.matched) {
      const seasons = [...new Set(episodes.map((e) => e.parsed.season))].sort((a, b) => a - b);
      for (const season of seasons) {
        if (show.seasons[season]) continue;
        try {
          show.seasons[season] = toSeasonInfo(await client.seasonDetails(show.tmdbId, season));
        } catch (err) {
          // Its episodes stay unmatched ("Épisode N") and the season is fetched again next scan.
          stats.errors++;
          logger.error?.(`TMDB lookup failed for "${show.title}" season ${season}: ${err.message}`);
        }
      }
    }
    shows[key] = show;
    for (const base of episodes) {
      const info = toEpisodeInfo(base, show);
      result.push(info);
      if (info.matched) stats.matched++;
      else stats.unmatched++;
    }
  }

  const tasks = [
    ...moviesToLookUp.map((base) => () => lookUpMovie(base)),
    ...[...episodesByShow].map(([key, episodes]) => () => lookUpShow(key, episodes)),
  ];
  stats.lookedUp = moviesToLookUp.length + [...episodesByShow.values()].reduce((n, list) => n + list.length, 0);
  if (tasks.length) {
    client = tmdb ?? createTmdbClient(config.tmdbApiKey);
    await runPool(tasks, (task) => task());
  }

  // Shows of episodes that weren't looked up, then only seasons that still have a file.
  for (const item of result) {
    if (item.kind === 'episode') shows[item.showKey] ??= previous.shows[item.showKey] ?? unmatchedShow(item.showKey, item.showKey);
  }
  for (const show of Object.values(shows)) {
    const seasons = new Set(result.filter((m) => m.showKey === show.key).map((m) => String(m.season)));
    show.seasons = Object.fromEntries(Object.entries(show.seasons).filter(([n]) => seasons.has(n)));
  }
  stats.shows = Object.keys(shows).length;

  result.sort((a, b) => a.file.localeCompare(b.file));
  const present = new Set(files.map((f) => f.file));
  stats.removed = previous.movies.filter((m) => !present.has(m.file)).length;
  await writeMoviesInfos(config.moviesInfosPath, { updatedAt: new Date().toISOString(), movies: result, shows });
  return stats;
}

// Episodes of TV shows: watching order, next episode and where to resume a show.
// Pure functions (no DOM) so they can be unit-tested with node --test.

const isConverting = (item) => ['queued', 'converting'].includes(item.conversion?.status);

/** Episodes of a show, in watching order. */
export function showEpisodes(movies, showKey) {
  return movies
    .filter((m) => m.kind === 'episode' && m.showKey === showKey)
    .sort((a, b) => a.season - b.season || a.episode - b.episode || a.file.localeCompare(b.file));
}

/**
 * The episode to play after `current`: a later episode of the same season (past every episode a
 * multi-episode file contains, and past other copies of it), then the next season. Episodes being
 * converted can't be played and are skipped.
 */
export function nextEpisode(episodes, current) {
  const after = episodes.slice(episodes.findIndex((e) => e.id === current.id) + 1);
  return (
    after.find(
      (e) => !isConverting(e) && (e.season > current.season || (e.season === current.season && e.episode > current.episodeEnd)),
    ) ?? null
  );
}

/**
 * Where "Lecture" takes a show: the episode with the latest activity if it's in progress, the one after
 * it if it was finished (null after the last one), the first episode if nothing was watched yet.
 * `date` is that latest activity, used to sort "Reprendre la lecture".
 */
export function showResumeTarget(episodes, progress, watched) {
  let last = null;
  for (const episode of episodes) {
    const started = progress[episode.id]?.updatedAt;
    const finished = watched[episode.id];
    if (started && (!last || started > last.date)) last = { episode, date: started, finished: false };
    if (finished && (!last || finished > last.date)) last = { episode, date: finished, finished: true };
  }
  if (!last) return { episode: episodes[0] ?? null, resume: false, date: null };
  if (!last.finished) return { episode: last.episode, resume: true, date: last.date };
  return { episode: nextEpisode(episodes, last.episode), resume: false, date: last.date };
}

/** "S1:É2", or "S1:É1-2" for a file holding two episodes. */
export function episodeLabel(episode) {
  const range = episode.episodeEnd > episode.episode ? `${episode.episode}-${episode.episodeEnd}` : String(episode.episode);
  return `S${episode.season}:É${range}`;
}

```js
async function playMovie(movie, { restart = false } = {}) {
  if (isConverting(movie)) return;
  playing = movie;
  let startAt = 0;
  if (restart) {
    delete progress[movie.id];
    api(`/api/progress/${movie.id}`, { method: 'DELETE' }).catch(() => {});
  } else if (progress[movie.id]) {
    startAt = progress[movie.id].position;
  }
  const next = isEpisode(movie) ? nextEpisode(showEpisodes(movies, movie.showKey), movie) : null;
  playingNext = next;
  document.body.classList.add('no-scroll');
  player.open(movie, {
    startAt,
    title: isEpisode(movie) ? `${shows[movie.showKey]?.title ?? ''} · ${episodeLabel(movie)} · ${movie.title}` : movie.title,
    next: next && { label: `${episodeLabel(next)} · ${next.title}`, onPlay: () => playNext(next) },
  });
}

/** Leave the current episode as watched and start the next one from the beginning. */
function playNext(next) {
  stopAutoSave();
  saveProgress({ finished: true });
  playMovie(next, { restart: true });
}
```

(`saveProgress` builds its request from `playing` and `video` synchronously, before `playMovie` switches them.)
